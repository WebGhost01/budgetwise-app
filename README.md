# BudgetWise — Personal Finance Tracker

Track income, expenses, and budget goals with beautiful charts.

## Features
- Log transactions with categories
- Monthly budget goals
- Visual spending breakdowns
- Financial overview dashboard

## Stack
React 19 · TypeScript · Tailwind CSS · Vite · Recharts · React Query · Shadcn/UI

## Run
```bash
npm install && npm run dev
```
Requires [portfolio-api-server](https://github.com/WebGhost01/portfolio-api-server).
